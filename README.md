# World Happiness Report 2015 — Exploratory Data Analysis

## 📌 Описание проекта

Данный проект посвящён исследовательскому анализу данных (Exploratory Data Analysis, EDA) на основе датасета **World Happiness Report 2015**.  
Цель проекта — изучить факторы, связанные с уровнем счастья населения в разных странах, а также выявить общие закономерности и региональные различия.

Проект выполнен в формате анализа данных и ориентирован на демонстрацию навыков работы с данными, визуализации и интерпретации результатов.


## 📋 Цели и задачи проекта

**Основная цель:**  
Проанализировать взаимосвязи между уровнем счастья населения и социально-экономическими показателями стран.

**Задачи проекта:**
- провести первичную подготовку и анализ структуры данных;
- выполнить исследовательский анализ числовых признаков;
- выявить линейные зависимости между показателями;
- проанализировать различия между регионами мира;
- сформулировать и проверить исследовательские гипотезы.


## 📊 Используемый датасет

- **Источник:** World Happiness Report 2015 (https://www.kaggle.com/datasets/unsdsn/world-happiness)
- **Количество стран:** 158  
- **Количество признаков:** 12  

Основные показатели:
- `Happiness Score`
- `Economy (GDP per Capita)`
- `Health (Life Expectancy)`
- `Family`
- `Freedom`
- `Trust (Government Corruption)`
- `Generosity`


## 🔍 Исследовательские гипотезы

В рамках проекта были сформулированы следующие гипотезы:

1. Уровень счастья населения положительно связан с уровнем экономического развития страны (ВВП на душу населения).
2. Продолжительность жизни населения положительно связана с уровнем счастья.
3. Социальная поддержка оказывает положительное влияние на субъективное восприятие счастья.
4. Уровень щедрости населения имеет положительную связь с уровнем экономического развития страны.
5. Экономическое развитие страны связано с продолжительностью жизни населения.

Проверка гипотез осуществлялась с помощью корреляционного анализа и визуализации данных. Подробное обоснование и интерпретация результатов представлены в ноутбуках проекта.


## 🧪 Этапы анализа

### Шаг 1. Подготовка данных
- загрузка и первичный осмотр датасета;
- анализ структуры и типов данных;
- проверка на пропущенные значения и дубликаты;
- изучение описательной статистики;
- визуализация распределений ключевых признаков.

### Шаг 2. Исследовательский анализ
- построение корреляционной матрицы;
- анализ линейных зависимостей между показателями;
- построение диаграмм рассеивания для ключевых пар признаков;
- интерпретация выявленных связей.

### Шаг 3. Группировка и сравнение данных
- группировка стран по регионам;
- сравнение регионов по средним значениям показателей;
- анализ региональных различий в уровне счастья и сопутствующих факторов;
- выявление общих тенденций и ограничений усреднённого анализа.


## 📈 Основные выводы

- Уровень счастья наиболее тесно связан с экономическим развитием страны, социальной поддержкой и продолжительностью жизни населения.
- Экономически более развитые регионы, как правило, демонстрируют более высокий средний уровень счастья.
- Продолжительность жизни положительно коррелирует с уровнем ВВП на душу населения.
- Уровень щедрости населения не показывает выраженной линейной зависимости от экономического развития.
- Региональный анализ позволяет выявить устойчивые различия между частями мира, однако усреднение показателей не отражает индивидуальные особенности отдельных стран.
